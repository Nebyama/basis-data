Keunggulan versi baru

  • Tidak perlu PHP, MySQL, atau XAMPP.
  • Siap dipublish di GitHub Pages.
  • Input data baru langsung dihitung otomatis.
  • Mudah di-commit ke GitHub.

1. Tanpa backend

Semua halaman dibuat dengan HTML, CSS, dan JavaScript murni, sehingga aman untuk GitHub Pages.

2. Perhitungan otomatis

Setiap data baru langsung dihitung menggunakan rumus ORESTE yang sudah ada pada versi PHP.

3. Mudah dikembangkan

Anda bisa menambahkan tampilan, chart, atau export data nanti tanpa mengganti arsitektur.

Catatan

Bagaimana cara publish ke GitHub Pages

  1. Commit semua file yang ada di folder ini ke repository Anda.
  2. Buka Settings → Pages pada GitHub.
  3. Pilih branch main atau master, folder /root.
  4. Simpan, lalu tunggu deploy selesai.
